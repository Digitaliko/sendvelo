### Description

```
Thumbway brings approval workflows to ChatGPT. Stop the endless email chains and Slack pings - send content for review, track who's seen it, and get sign-off without leaving your conversation.

The Problem We Solve:
You just created something great with ChatGPT - a proposal, marketing copy, a strategy doc. Now you need approval. So begins the chaos: forwarding emails, chasing reviewers, losing track of who said what. Meanwhile, your content sits in limbo.

What Thumbway Does:
We make getting approval as easy as asking for it. Send content to reviewers directly from ChatGPT, track engagement in real-time, and nudge people who haven't responded.

Core Features:
Send any content for approval - documents, proposals, marketing copy, anything created in ChatGPT. Just describe who should review it and how many approvals you need.

Track reviewer engagement - See who viewed your content, when they viewed it, and how long they spent. Know exactly where things stand without asking.

Smart follow-ups - Generate AI-crafted nudge messages based on how long someone's been waiting and whether they've even opened your content.

Multiple workflow types - Need everyone to approve? Just one person? Approvals in sequence? We support parallel, sequential, and any-one workflows.

Share and export - Get a public link for your approved content, export with approval metadata, prove sign-off happened.

Perfect for:
- Freelancers getting client sign-off on deliverables
- Small teams needing internal approvals without enterprise tools
- Content creators sharing work for feedback before publishing
- Anyone tired of "did you see my email?" follow-ups

Current Features:
- Send content for review to up to 10 reviewers
- Three workflow types (parallel, sequential, any-one)
- Real-time engagement tracking (views, time spent)
- AI-generated nudge messages (friendly, professional, urgent tones)
- Reviewer management (add, remove, remind)
- Public sharing with configurable access levels
- Export approved content with metadata
- Interactive widgets showing approval progress
- No complex setup - works immediately with email

Thumbway is the missing piece in your ChatGPT workflow. Create content, get it approved, ship it. All in one conversation.

Get started: Just ask ChatGPT to "send this proposal to client@email.com for approval" or "check the status of my marketing copy review."
```

## Tool Metadata Documentation

### Tool 1: `send_for_review`

**Tool Name**: `send_for_review`

**Title**: `Send Content for Review`

**Description**:
```
Send content for approval to one or more reviewers. Supports parallel, sequential, or any-one approval workflows. Shows confirmation widget with next actions. Use when the user wants to get approval, sign-off, or feedback on content they've created.
```

**Input Schema**:
```json
{
  "type": "object",
  "properties": {
    "title": {
      "type": "string",
      "description": "Title of the content to review"
    },
    "content": {
      "type": "string",
      "description": "Content to review (markdown supported)"
    },
    "reviewers": {
      "type": "array",
      "items": {"type": "string"},
      "description": "Email addresses of reviewers (1-10)"
    },
    "workflowType": {
      "type": "string",
      "enum": ["parallel", "sequential", "any_one"],
      "description": "Workflow type"
    },
    "format": {
      "type": "string",
      "enum": ["plain_text", "markdown", "html"],
      "description": "Content format"
    }
  },
  "required": ["title", "content", "reviewers"]
}
```

**Annotations**:
```json
{
  "readOnlyHint": false,
  "destructiveHint": false,
  "openWorldHint": true
}
```

**Annotation justification**:
- **readOnlyHint: false** - Creates review records, sends emails
- **destructiveHint: false** - Creates new content, doesn't delete
- **openWorldHint: true** - Sends emails to external recipients
