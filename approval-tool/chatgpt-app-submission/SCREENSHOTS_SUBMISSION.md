## Screenshot Capture Tips

1. **Pre-populate test data** - Have sample reviews ready before capturing
2. **Use browser zoom at 200%** to capture retina quality
3. **Capture at 1412px width** (2x of 706px) then resize to 706px
4. **Capture clean widget** - No browser chrome, just the widget content
5. **Show interactive elements** - Buttons, progress bars, action items
6. **Use light theme** for better visibility
7. **Ensure data looks realistic** - Real names, plausible content

## Quick Workflow

### For Widget Screenshots:

1. Open ChatGPT with Thumbway connected
2. Complete OAuth if needed
3. Paste prompt from above
4. Wait for widget to fully render
5. Zoom browser to 200%
6. Screenshot just the widget (not browser chrome)
7. Crop to 1412px width (maintaining aspect ratio)
8. Resize to 706px width for final PNG

### For Dashboard Screenshots:

1. Ensure multiple reviews exist in account
2. Vary statuses (pending, approved, rejected)
3. Include different reviewers
4. Request dashboard view
5. Screenshot the full widget

## What Makes Good Screenshots

**Do:**
- Show realistic data (actual names, plausible content)
- Highlight engagement data (views, time spent)
- Show variety of statuses
- Include action buttons
- Make widgets clearly readable

**Don't:**
- Use placeholder text ("Lorem ipsum")
- Show error states
- Include personal/sensitive data
- Crop off important UI elements
- Use low-resolution captures
